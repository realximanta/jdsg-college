## 🏛️ About the College
**Jogananda Deva Satradhikar Goswami (JDSG) College**, established in 1964, is a premier educational institution located in Bokakhat, Golaghat, Assam. Affiliated with Dibrugarh University and recognized under the UGC Act, the college is dedicated to its vision of *"Education for Social Justice and Peace."*

## 💡 Why this App?
- 📱 **Missing Presence:** Despite its rich history, JDSG College currently lacks a dedicated mobile application for students and faculty.
- 🛠️ **Vibe Coding:** This project is also a personal challenge to test rapid, AI-assisted "vibe coding" capabilities, building a production-ready full-stack app from scratch.
- 🎯 **The Goal:** To provide a seamless digital experience for students and teachers to access notifications, update profiles, and eventually locate rooms and check routines.

## 🛠️ Tech Stack
- **Android App:** Kotlin, Jetpack Compose
- **Backend:** Go (API), Python (Scraping), Docker
- **Database & Storage:** Cloudflare Workers KV, Cloudflare R2
- **CI/CD:** GitHub Actions
- **Hosting:** Render (Backend), Cloudflare (Storage/DNS)
